# EvolvingDigitalClassics-2025-Stylometry-Tutorial

Data and code (including tutorial notebooks) for reproducing Bolt et al., “Stylometry for Latin Literary Criticism,” in *Evolving Perspectives on Digital Classics*

## Citation

If you use the code or data in this repository, please cite:

> T. J. Bolt, K. Bui, P. Chaudhuri, and J. P. Dexter. “Stylometry for Latin Literary Criticism.” In *Evolving Perspectives on Digital Classics*, edited by C. R. LaMonica and A. Foka, 114–134. Routledge, 2025. https://doi.org/10.4324/9781003584155-10.
